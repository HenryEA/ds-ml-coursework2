Analysis of daily adjusted closing prices for SPY and TLT, focusing on price performance, equity-bond diversification, rolling correlation, and daily return distributions.

## Objectives

This project analyses SPY and TLT price data to:

* Construct normalized price series starting at $100
* Compare the performance of equities and long-term bonds
* Identify a six-month period when both assets declined
* Analyse the 60-day rolling correlation between SPY and TLT
* Identify periods of positive and negative correlation
* Calculate daily returns for both assets
* Summarize the empirical distribution of daily returns
* Interprete the relationship between equity and bond performance

## Methods

The analysis uses Python and includes:

* Pandas
* NumPy
* Matplotlib
* Yahoo Finance data
* Price normalization
* Rolling correlation analysis
* Daily return calculation
* Descriptive statistical analysis
* Financial time-series analysis
